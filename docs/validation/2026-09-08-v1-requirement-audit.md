# v1 requirement/evidence audit — 8 September 2026

This is an explicit inventory of retained v1 requirements and remaining proof, not release sign-off.
Inspected checkout baseline: `2cbd398`, plus pre-existing user changes (including depot-boundary
recovery) and this handoff implementation. Earlier validation notes describe the exact runs they
record, not the current installed bundle. App version 0.1 is not proof of v1 acceptance.

## Decisions and concrete gaps

- The user resumed implementation. Historical “all work paused” statements are stale. Big Screen
  was running from `/Applications` at the new audit's start; desktop/game testing is pending
  availability. Do not replace that running bundle from build/test commands.
- PRD FR-LAUNCH-2 and adopted design both specify indefinite waiting with an exit escape hatch.
  The conflicting proposed 60-second delayed state is not adopted; the plan now says so explicitly.
- Retain the generic Focus tree/nearest-geometry and separate Artwork target requirements. This
  pass moves fetch/decode/disk-cache/cancellation into a UI-independent Artwork target with its
  loader tests. App retains the NSImage/memory presentation adapter. Generic Focus is still missing.
- Plan corrections add Domain/Sessions, cardinal resolution of diagonals, dark-only v1, informational
  toasts with durable recovery actions, account-local retained installs, original verification before
  staging, Cloud instead of optional local uninstall retention, and Home return. They do not remove
  the physical/controller/performance release gates. The adopted 3b cover uses a download glyph and
  only Broken compatibility badges; the older brief's dimmed covers/all-rating badges are historical.
- Fixes in this pass: quit consequences cannot be replaced by errors; diagnostic text has a bounded
  layout; PS tap is emitted on release and a hold does not also emit Home. Test hosts do not activate
  windows/controllers/services or exit when a test window closes. Original/final verification now
  shows actual checked-byte percentages across Downloads, details and the compact indicator.
- Private `/tmp/bigscreen-launcher-quit-ui.swift` now fails cleanly when its expected old staged process
  is missing. Its bundle identifier/path are historical; do not retarget or reuse stale runtime JSON
  without freshly verifying process/start/window identity. Global Shift–Home proof uses System Events.
