# Cloud UI and production wiring — 8 September 2026

The production LibraryModel creates CloudSyncService with the authenticated Steam reader/writer,
CloudSaveAccess ownership checks and SteamSaveValidation. SessionService receives that coordinator
for pre-launch and post-exit synchronization. Background manual sync is cancelled and joined before
sign-out or application shutdown.

Installed game details expose a Cloud saves action and status in the footer. Conflict review shows
both copies' dates, counts, sizes and transfer direction. Choices use the displayed operation's
versioned authorization; the service remains responsible for rejecting stale consent. Opening a
review initially focuses Close/Cancel launch, so opening it cannot implicitly select a save.
Retry, explicit safe offline play and account attachment are reachable with directional input.
Unsupported mappings display Unavailable. Closing a background transfer's panel leaves its durable
work running; cancelling a waiting launch releases its session reservation. Post-exit sync returns
to the launcher and disables game controls for the stopped runtime.
